Test details

1. Question paper

Upload the question paper: ScoreSense reads the marks scheme and every question, then writes the rubric (the multiple-choice answer key and the marking points of each written answer) for you to check below. Or upload the official marking scheme (for example CBSE's): its answers, value points and marks are copied as printed, which is more reliable.
Check the rubric ScoreSense wrote
ScoreSense wrote the answers for the questions marked AI from its own knowledge, which is not always right. Check the key and the points, change what is wrong, then confirm.

2. Marks

SectionQuestionsTypeMarks eachMarks
Question numbers and marks for each, like 1-20:1, 21-24:2; a part can have its own, like 34.1:1. Total: 0 marks.

3. Multiple-choice answer key

Click the correct option for each question. Options printed as (a)–(d) or (i)–(iv) are the 1st to 4th: A = (a) = (i).

4. Marking points for written answers

For each written question, list what an answer must say to earn its marks, one point per line, with one idea per point (as in the official marking scheme). ScoreSense reads each student's answer, checks which points it makes, quotes the student's words for each, and suggests marks for you to confirm. Questions without points are marked by you as usual.
