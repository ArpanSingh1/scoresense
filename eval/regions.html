Answer regions

Draw a box around each answer area on the blank sheet, then download regions.json for cut_crops.py.
How to draw regions
  • Use the same blank sheet image you will give cut_crops.py as --template.
  • Drag on the sheet to draw a box; it gets the next free name (Q1, Q2, ...). Rename it in the list.
  • Cover the whole space a student might write in, including past the printed lines.
  • Never include the name, roll number or any other identifying field.
  • Click a box to select it; Delete removes it. Arrow keys nudge it, Shift+arrows resize it.
  • For a multi-page paper, draw each page's image with its page number; open the saved regions.json first so the other pages are kept.
